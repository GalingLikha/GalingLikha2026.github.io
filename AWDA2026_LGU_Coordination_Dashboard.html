  • Weaves & Materials — the weave traditions, techniques, and fibers named in each application.
  • Galing Pook — invitation letters sent to LGUs, with follow-up and endorsement status to track going forward.
  • DoST‑PTRI — weaver-assisted training log (yarn/fiber training availment), with a status column.
  • TESDA — a working tracker; no source data was provided for this workstream yet.

Data quality notes

  • One application ("TEST LGU") is a test submission and is excluded from every count on this page.
  • One application ("Dulag") had a blank province/region in the form; filled in here as Leyte / Region VIII based on the LGU name — worth confirming with the submitter.
  • One province value had a stray trailing character, cleaned up for matching purposes.
  • Several Galing Pook rows have a role title, an email address, or a placeholder in the LGU/province field instead of an actual place name — these are flagged rather than silently counted.
  • Region-level targets here are the sum of each province's individually-rounded 20% figure (327 LGUs nationally), which differs slightly from the source file's own subtotal rows (332) — a rounding artifact in the original pipeline.
  • "Application received?" on the Galing Pook tab is a best-effort name match, not a confirmed lookup — check it against the DTI‑MTIT tab before reporting it as fact.
  • "Fiber / Raw Material Used" is a multi-select field in the source form (fibers are newline-separated); the materials chart counts each fiber named, so totals across fibers can exceed the number of applications.

Needed-support criteria (DTI–MTIT tab)

  • Critical — a target above zero with no applications received yet.
  • Needs support — applications received are below 50% of target.
  • On track — applications received are at or above 50% of target.
